## 0.5.0

Session and tool guards: max_tool_rounds, send_timeout, tool_call_timeout, max_turn_tokens. Per-tool timeout on Tool dataclass.

### Features

- **New.** Guard fields on SessionConfig: max_tool_rounds, send_timeout, tool_call_timeout, max_turn_tokens.
- **New.** Per-tool timeout field on Tool dataclass and @tool decorator.
- **New.** Enforce max_tool_rounds, send_timeout, and max_turn_tokens guards in direct sessions.
- **New.** Enforce per-tool timeout in _dispatch_tool().
- **New.** Forward guard fields in _build_invocation_config() for invoke-mode sessions.
