## 0.2.0

Auth style support and OpenAI compatibility fixes.

### Breaking

- **auth_style required.** SessionConfig now requires auth_style when api_key is set. Supports 'bearer' (OpenAI) and 'x-api-key' (gateway).

### Fixes

- **OpenAI compatibility.** Tool result content is now JSON-serialized when non-string.
- **OpenAI compatibility.** Assistant messages always include content key for tool-calling conversations.
